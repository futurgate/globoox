# Архив перед восстановлением Reader

Сохранены прежний изменяемый план bookshelf и апрельский server-snapshot RFC. Причина: bookshelf v2 выпущен, дальнейшие Reader defects имеют другой активный план. [Текущий план](../../rfcs/active/reader-recovery-2026-10-01/README.md). Старые ссылки внутри snapshots исторические; фактические evidence/rollback остаются в исходном каталоге. Пользовательские файлы, landing/billing RFC, незавершённые исходники и worktrees не архивировались и не удалялись.
