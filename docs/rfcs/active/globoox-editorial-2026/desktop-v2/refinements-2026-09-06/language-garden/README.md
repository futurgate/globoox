## Root selection

Generated eight independent full-section studies and two further edits with the built-in ImageGen tool. Root visually inspected all ten. **Root favors [Orchard / Молодой сад](orchard.png)**: natural sparse growth gives the four current cards and upcoming seedlings one coherent meaning. It is a promising design direction, not an assertion of finished implementation. [Review all variants](index.html).

The two follow-up edits did not improve the original enough to replace it. `orchard-refined.png` introduced more foliage and overlarge staged seedlings. `orchard-quiet.png` reduced card legibility too far and moved upcoming text toward the outer edge. Preserve these as visible history, not selected assets.

Second promising direction: [Little editions / Маленькие издания](little-editions.png), whose bookmark-like cards connect directly to reading. Its four decorative styles need unification and the assembly is oversized. [Seed tree / Тонкий побег](seed-tree.png) is the reserve botanical drawing language: airy, but currently resembles a timeline more than a tree. An independent critique preferred those two over Orchard; root chooses Orchard for the clearer mature/upcoming relationship while acknowledging its possible family-tree/stationery association. None of these claims supersedes user feedback or approves deployment.
